# Delilah Beverly: portfolio

My personal portfolio site, live at https://isledeli.github.io/

A single page in plain HTML and CSS: no build step, no JavaScript, no external fonts or scripts.

- `index.html`: the page (about, experience, projects, skills, contact).
- `styles.css`: all styling. Colors, type and spacing are variables at the top of the file; the page follows the system light or dark setting.

To edit, change the text in `index.html`, open the file in a browser to check it, then commit and push to `main`.
